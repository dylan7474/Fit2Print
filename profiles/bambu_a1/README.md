Bambu A1 profile files for the Bambu Studio command line (copied from Phonosphere's a1/profiles, 2026-10-30; derived from Bambu Studio's own profiles with our edits).
* `machine.json`: A1, 0.4 mm nozzle.
* `process_0.28_manual_support.json`: 0.28 mm Extra Draft, 3 walls; supports are ON but only where painted, so with nothing painted a part prints without any.
* `pla_black.json`, `pla_white.json`: the cheap PLA used so far.
Limits the checks judge against are in `../bambu_a1_pla.toml`.
