# Lessons: each real failure and the check it became

(From Phonosphere, 2026-10-16 onwards. The check column says where it lives or will live.)

| Failure | What it cost | Check |
|---|---|---|
| A line over air judged by length, not by what held it up: a groove broke out of a corner | a print | toolpath check: cantilever depth and sides held, not line length |
| Arches printed on an unsupported lap shelf | a failed print | unsupported-plastic check; never print a flagged plate without looking |
| Supports filled blind pilots and small holes | a failed print | as-built check: supports inside small holes |
| Seam bolts unreachable with a driver (hand tried it: an hour for 4 bolts) | a redesign | fixings check: a 6 mm rod, 100 mm long, straight from outside to the head |
| Bolt holes passing through air, not plastic | a redesign | fixings check: plastic around each hole |
| The file named on the command line was a stale STL from an older design | three "checks" of the wrong part | refuse any STL older than the model; rebuild or stop |
| The as-built check tried only 0/90/180/270 turns; the slicer had turned the plate 45 degrees | false "missing" and "extra" | find the turn angle by chamfer distance |
| A pod lid collided with turned lugs | a part that would not fit | fit check: part against part |
| A lug's wedge was cut short by the pod, leaving a flat 4 mm shelf: ragged print | a coupon | layer slicer: z-step in area; fix by flush lug and 45 degree underside |
| A screw foot with a flat 4 mm underside, spotted by hand in the slicer | a check that missed it | wedge under every protruding boss; the checker now needs a case for it |
| The pod cannot be pushed in or out through the open back (six lugs in the way) | would have been found at assembly | assembly sweeps, in the real order |
| A check test that models the wrong gap (the plates lock a 1.5 mm gap) | a false alarm | model the gaps the real build has |
| `pgrep -f` matches its own command line: false "still running" | hours of stuck waits | wait on a PID with `kill -0` |
| A tool printed a secret into the log while looking something up | a credential exposed | print only the fields you mean; mask by default |
| A fix was "done" on paper (cone-tipped holes, painted supports) but no real print had tried it, and the user rightly asked for a test | a doubt that stayed open for four days | **coupon**: cut the doubtful spots from the part's own STL and print them together (`fit2print coupon`); call a fix "checked", not "proven", until a print shows it |
| The first coupon covered one spot; the real failure had several (shelf, tab, two kinds of blind hole) | a second round of planning | one plate of several coupons, one from each way the part can go wrong, all with the part's own slicer settings |
| A check that passes proves nothing until it is seen to fail; the known-bad plate used as the control was a whole part and timed out at 250 s | a control that never finished | known-bad fixtures must be **small coupons** (a 56 mm region slices and checks in 20 s): the old flat-pilot end with auto supports gives BLOCK, the new end passes |
| The geometry cure (a 45 degree drill-point tip) held even under auto supports; the settings cure (painted supports only) is a second layer | confidence | test both: the fix must pass with the setting that once broke it, so it does not depend on one setting staying right |
| "I can't see how it connects": blind screw holes and screws from the inside show nothing from the front | an afternoon of doubt | a pulled-apart picture from the real model (shell, lugs, screws, face); say which printed pieces have a counterpart yet (the sunburst bolts to shell_upper, which is not printed) |
| Test prints made before a design change look right but have fixings in the old places | wrong conclusions from a hand fit | every printed piece records the design hash it was made from (PLATE_RESULTS `design_sha`); warn when a design change moved a fixing |
| Which way up a part prints decides what is an overhang: tabs on the bed are free, the recess a tab sits in is a shelf in the air | confusion over "tab up / tab down" | say the print orientation and name each overhang (which seam, how wide, how high) in every report |
| "Cut where the outline is shortest" steered a cut into the LED window: a window shortens the outline | a cut through the display | cut choice is by section topology (separate pieces and holes), then local change, then nearness to an even split; negative control with a real window |
| A relative output folder: OpenSCAD runs elsewhere, found no part, and every section looked "empty" (100% of the volume lost) | a silent wrong answer | all paths absolute; a real OpenSCAD complaint is a failure, only a plain "empty" is a gap; the volume check (sections + pin holes = the part) caught it |
| A screw hole's counterbore cut through the back plate's lip ring: the exported STL was not watertight | a model flaw found only by a warning | check that a screw's hole passes only through the part it belongs to (to do) |
| A model drawn in print orientation (face on the bed) gives upside-down pictures with `view = "bottom"` | a confusing render | say so in the render help; use `angle = [180, 0, 180]` for the bed side |
| `plate` slices one STL at a time, so eight sections meant eight commands | friction | `plate --split NAME_split.json` slices every section and the pin plate (done) |
| Walls too thin for pins (a 2 mm box) were left "join with glue" | the splitter gave up exactly where large thin-walled prints (cases) need it | `joint=auto`: pins where two fit, otherwise a chessboard of 45 degree pyramid teeth on that seam (works in any wall, locks both ways) |
| Square teeth left 2.5 mm overhangs when the seam stood vertical on the bed (the plate check said CHECK) | a joint that needs supports | teeth with 45 degree sides: both sections PASS with no notes |
| A zero-thickness slab in an OpenSCAD hull vanished, so the pocket was never cut and two pieces overlapped | a joint that looked fine in the report | the volume check caught it (pieces totalled MORE than the part): the check now accepts a loss between 0 and a bound, and fails on a gain |
| Support painting lived only in Phonosphere's make_plate.py, so a new project's shelves printed in the air (or auto supports filled the pilots) | the boss-hole failure could come back in any project | `support.py` + `plate --supports auto` (default): shelves painted, re-sliced, support inside a small hole BLOCKs; control: auto supports on the same part are caught |
| An old negative control ("an unpainted shelf must BLOCK") stopped being one the moment painting became the default | a control that quietly tests nothing | the control now passes `supports="none"`, and a twin test shows the painted shelf passes |
| The as-built check tried the slow pose fit (a fitted rotation angle) BEFORE the obvious pose, and every pose at full resolution: one 244 x 177 mm section took 552 s | a check nobody would wait for gets switched off | poses are tried lazily, scored on ~8 sampled layers, the winner is checked in full, and only a dirty full result triggers the exhaustive search (26 s) |
| A sampled score said "pose 0 fits" because the sample skipped the one layer that disagreed; the full check then showed a MISSING that a 0.4 degree rotation removes | a speed-up that changes the answer | never trust the sample for the verdict: the verdict always comes from a full-layer check, and a dirty one re-runs the full search |
| Phonosphere matched plate objects to parts by SIZE, so mirror twins were ambiguous and a part with shelves could be skipped | a mirror pair is the commonest multi-part plate | objects are matched by file NAME from the 3MF (an unknown name is an error); a test slices a mirror pair and checks both are painted |
| Parts that must print the other way up (the louvre) were a hard-coded name list in a script | the orientation was invisible to every other check | `orient = "flip_x"` in the `[[export]]` table: the STL is written already turned over, so every check sees what is printed |
| Phonosphere could not be pointed at Fit2Print: its parts are called shell_lower_L (capital letters) and its STLs live in stl/full, not stl/ | the first real project exposed two limits the samples never hit | `stl_dir` in the marker (refused if outside the project) and export names may use capital letters |
| Moving a project onto the tool: 31 parts exported, volumes and sizes within 0.1% of the old STLs, and 8 plates re-sliced reproduce the old verdict, minutes, grams and painted-face counts | proof the extraction lost nothing | keep this comparison as the acceptance test whenever a check is moved out of a project script |
| Re-slicing all 31 Phonosphere parts: 30 matched the old verdict/minutes/grams (incl. the four CHECKs the old tool also raised); `port_sleeve` BLOCKED "a shelf needs support but no faces could be painted" | the old tool had never really judged that part (its only record was a 0-minute audit) | an overhang's span is now min(distance along the region, straight-line distance to the layer below): a 1-px sliver at a bore's apex read 62 mm along itself but is 4.8 mm from the wall. Across all 31 parts only this region changed |
| The virtual build lived in a Phonosphere-only OpenSCAD harness and script | any new project would have had no way to test that a part can be put on, or that a screw lands | `assembly-check` + `checks.toml`: [[sweep]] and [[screw]] cases, parts drawn in assembled places (a model part value or an OpenSCAD snippet); Phonosphere's 5 sweeps and 34 screws reproduce the old numbers exactly (129 mm3 shell touch, bites 6/4/8/6 mm) |
| A sweep sampled every 8 mm can jump over a 4 mm rib (my first test lid sailed past a bar) | the original check had the same blind spot | default step 2 mm, and a visible WARNING for any larger step |
| The "4 % too big" control cannot work for a container closing round something: a bigger shell has a bigger cavity | the control reported "your checker is blind" when only the control was wrong | the control grows the moving part OR the fixed parts, and either colliding proves the check can see |
| `part = "x"` in Phonosphere draws the PRINT layout (flat, spread out), not the assembled place | a generic check fed those parts and every screw bit 0.0 mm | parts may be defined in checks.toml as OpenSCAD snippets (with a prelude that includes the model) |
| check_fit.py and check_fixings.py were two more Phonosphere-only scripts, run line by line from OpenSCAD cases | any new project would have had no overlap, driver-run or plastic-round-the-hole checks | `[[probe]]`, `[[driver]]` and `[[ring]]` in checks.toml with controls that must fire; Phonosphere's 54 probes, 10 driver groups and 8 ring groups give the same answers as the old scripts (258 and 402 mm3 accepted overlaps, 99 % and 93 % plastic rings, 62 fixings checks) |
| A mid-air control that slides the ring 60 mm sideways stays inside a long flange (seam pins read 99 %) | the control said the checker was blind when the control was weak | the ring control tries six directions and needs only one to find air |
| Phonosphere's selftest (plates with KNOWN outcomes) was a Phonosphere-only script: a new project had no way to ask "is the checker still telling the truth?" | a green plate is only worth something if the checker still flags known failures | `fit2print selftest`: selftest.toml lists known-bad and known-good plates (toolpath and as-built) plus built-in synthetic cases; a disagreement says THE CHECKER IS NOT TRUSTWORTHY. All 12 of Phonosphere's fixtures give the old answers |
| Two whole-radio fixtures took 323 s and 373 s of a 14-minute self-test | a self-test nobody runs proves nothing | `slow = true` skips them by default, says so, never counts them as passed, and `--all` runs them; the default run is under 3 minutes |
| Check results only lived in the terminal (or an overwritten JSON) | nobody could see when a check last ran, or that it had started failing | records/checks.jsonl: append-only, one line per run (check, time, ok, counts) |
| Check records stored the time to the minute, so a check run in the same minute as a model save looked OLDER than the model and was flagged stale | a false "the model has changed" warning would teach people to ignore it | records carry exact epoch seconds (ts) and the page compares those; an old minute-only record still reads |
| The project page showed plates but nothing about the checks | a green check from last week for a model changed yesterday looks the same as a fresh one | a read-only Checks card: last run per check (CLEAR, FAILED, STALE if the model is newer, NOT RUN with the command to run), plus every split with its joints and warnings |
| The refusal page said "Open the link with its token" to someone coming through the Cloudflare tunnel, when no token existed (owner, 2026-11-01: "I asked you to remove this") | a message that sends people hunting for something that is not there, and looks like a token was added again | the message names the real reason (tunnelled request, Cloudflare Access not switched on for the hostname, no token to enter) and what to do |
| A token, a Cloudflare Access check, proxy-header detection and `--trust-lan` had been built into the web app; behind the owner's own tunnel the page said "Open the link with its token" (owner, 2026-11-01: "it should be JUST a website and I can provide access to it how I like") | the app took a security decision that belongs to whoever puts it on a network, and refused the very setup the owner chose | all of it removed: no token, no login, no knowledge of any proxy; flags `--token`, `--token-file`, `--trust-lan` and the [access] config are gone; a test fails if those words come back into the server |
| The one-page plate report (a picture of the real layer at every flagged spot) was only made by a Phonosphere script that needed matplotlib | the page a person reads before printing was the one thing that could not be produced for a new project | `fit2print report PLATE.3mf [STL...]` and `plate --report`: same findings and plain-English explanations, pictures drawn with pillow (no new dependency); tested with a plugged-pilot plate (BLOCK, with the spot shown) against its painted twin (not BLOCK) |
| A part whose file name contains & < > could not be matched on a shared plate: the 3MF stores names XML-escaped | found by a test using a deliberately awkward name | names are decoded when the plate is read |
| Calibration lived in a Phonosphere script that wrote Phonosphere-only files, and the shelf limit that decides where supports go was a number typed into the code (5 mm) | a different printer or filament would silently use the A1's numbers | `fit2print calibrate card` / `record`: one printed card -> a profile that every check reads (`--profile`); the shelf limit now comes from the profile (a test proves a calibrated 11 mm limit stops the plate painting an 8 mm ledge); hole and outside allowances go to printer_offsets.scad |
| It is easy to type 3.0:9.0 for a hole that measured 2.9 | a slipped digit would become a 6 mm "allowance" in every model | a reading more than about 0.35 mm from its drawn size is refused ("measure it again, or the print failed there"), never averaged in; the 2.5 mm hole is reported, not averaged |
| A card result nothing uses (wall_ok, lean_ok, pin) could look as if it were applied | false confidence | the command lists exactly what the checks use ("used by the checks: ...") and the docs say the others are recorded only |
| The parts register was a Phonosphere script with the part descriptions typed into its code | a new project could not list its parts, their fixings, which STL is stale or which part needs a reprint in one place | `fit2print register`: parts.toml describes the parts; plate checks, STL freshness and the print log are READ. Phonosphere's 38 parts reproduce (0 description differences); the differences were today's facts (shell_lower_R no longer needs a reprint, back_lower_L is printing) |
| The first version flagged 35 of 38 plates "from an OLDER STL" | a warning that fires on everything is ignored, and the old records hashed a different file | the STL fingerprint is compared only for plate records Fit2Print made; the others are counted and said once at the end of the page, never silently trusted and never flagged row by row |
| A part exported but not described, or described but never exported, is easy to lose | a missing row looks the same as a part that does not exist | UNREGISTERED and NOT EXPORTED are listed by name; `--strict` fails on them, on stale STLs and on never-checked parts |
