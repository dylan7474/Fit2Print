# GUI mock-ups (2026-10-30)

Pictures first, code second. Both are HTML drawn from real data (the radio, the Pi Zero sample, the printer camera); numbers marked as examples are examples.

1. `home.html` / `mockup_01_home.png`: Your projects. Cards with state and "Needs you", a printer panel (live camera, progress), an assistant panel, a New project button. **Approved by the user.**
2. `new_project.html` / `mockup_02_new_project.png`: Scope. One line to describe the thing, the assistant's questions as a form, the dimensions it cannot know (to be measured, marked UNVERIFIED), a live draft brief, the assistant chat, and one button to approve the brief and draw the first concept.

Rules the screens follow: one thing at a time, plain words, "needs you" always visible, never an invented number, works on a phone.
