# Pi Zero 2 W wall case

A snap-fit case that hangs on a wall or under a desk, for a Raspberry Pi Zero 2 W with its header fitted. A **sample project used to test Fit2Print** (the real-world case was the Phonosphere radio). It lives in the Fit2Print repo under `samples/` and has no repo of its own.
It is kept apart from the radio by its own folder and its own marker file.

* `brief.md`: stage 1, what it is for and what is still open.
* `case.scad`: the parametric model (proof-of-concept).
* Deliverables (renders, print files, photos) go in `~/Downloads/fit2print_samples/pizero_case/`, never in another project's folder.
