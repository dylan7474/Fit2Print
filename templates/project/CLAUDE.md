# Project rules for the AI (read at the start of every session)

This is a Fit2Print project. Follow `docs/PLAYBOOK.md` in the Fit2Print repo: session start and end protocols, the stages, and the standing rules. In short:
* Read `fit2print.toml`, `NEXT.md`, `brief.md`; run `fit2print dashboard`; say where the project stands in one or two plain sentences; then wait for a go-ahead.
* A question is not a go-ahead. One picture at a time, plain words.
* Never waive a check; the AI never marks its own work as passed; never invent a dimension; look before printing; coupons before big prints.
* Keep this project apart from every other: its own folder, records and output folder. Never read or write another project's files.
* End every session by recording what happened and rewriting `NEXT.md`.

Project-specific rules go below this line.
